Getting Started with MethylTraits

Andy Madrid

Lasted Edited: September 2, 2026

Introduction

MethylTraits works directly on BSseq objects (from the bsseq package) and covers two complementary jobs:

  1. Discovery – find and annotate regulatory methylation features across a cohort: imprinting control regions (findICRs, annotateICRs) and stochastic epigenetic mutations (findSEMs, annotateSEMs), plus gene-level burden association testing (testSEMBurden, testSEMGenes) and GO/KEGG enrichment (goSEMs) on top of them.
  2. Prediction – predict sample-level traits directly from WGBS methylation: genetic sex and sex-chromosome karyotype (predictSex), self-reported race/ethnicity (predictRace), PASC/long-COVID status (predictPASC), epigenetic age via a two-tier ensemble (predictAge), and 450K/EPIC array emulation for cross-platform work (emulateArray).

A third function, liftBuild, doesn’t belong to either group: it’s a preprocessing utility that converts a BSseq object’s coordinates between hg19 and hg38, for when your data isn’t already on the build a given function expects.

Nothing in MethylTraits requires you to train anything yourself: predictSex is purely coverage/copy-number based (no training data needed at all), and predictRace/predictPASC/predictAge/emulateArray ship with pre-trained models bundled inside the package (system.file("models", ..., package = "MethylTraits")) – you only ever supply a BSseq object.

Installation

# Bioconductor dependencies used throughout the package
if (!requireNamespace("BiocManager", quietly = TRUE)) install.packages("BiocManager")
BiocManager::install(c("bsseq", "GenomicRanges", "IRanges", "S4Vectors", "GenomeInfoDb"))

# from a locally built source tarball
install.packages("MethylTraits_0.1.0.tar.gz", repos = NULL, type = "source")

Most functions also need one or more packages listed under Suggests in DESCRIPTION (e.g. glmnet for predictRace/predictPASC, xgboost/ranger for predictAge, minfi for emulateArray) – install these as needed; each function will tell you at call time if something required is missing.

Example data

The examples below use a small subset of samples from an internal WGBS validation cohort that was used throughout this package’s development to validate every function against real data. Substitute your own BSseq object anywhere bs appears below.

suppressPackageStartupMessages(library(bsseq))
library(MethylTraits)

load(data_path)
bs <- bs.pasc3
rm(bs.pasc3)

# a 3-sample subset keeps the *prediction* examples fast; predictSex/predictRace/
# predictPASC/predictAge/emulateArray all work identically on cohorts of any size
bs_small <- bs[, 1:3]
sampleNames(bs_small) <- pData(bs_small)$"Sample ID"
bs_small

Genome build conversion

Our toy bsseq object is already on hg38, the build every other function in this package expects by default. If your own data is aligned to hg19 instead (or you need to move hg38 data down to hg19, e.g. to match an older annotation resource), liftBuild converts a BSseq object’s coordinates between the two via a UCSC chain file (fetched once and cached locally through AnnotationHub). CpGs with no equivalent locus in the target build are dropped, and genome(bs) is updated to reflect the new build.

bs_small_hg38 <- bs_small[as.character(seqnames(bs_small)) %in% c("chr21", "chr22"), ]
bs_hg19 <- liftBuild(bs_small_hg38, current = "hg38", new = "hg19")
#> [liftBuild]: will lift your bsseq object from hg38 to hg19
#> loading from cache
#> require("rtracklayer")
#> [liftBuild]: lifting over resulted in a loss of 31264 CpGs
dim(bs_small_hg38)
#> [1] 991522      3
dim(bs_hg19)
#> [1] 960258      3
unique(genome(bs_hg19))
#> [1] "hg19"

Part 1: Discovery

The discovery functions look for signal across CpGs genome-wide, so their runtime scales with how much of the genome you give them. To keep this vignette fast we restrict to chr21+chr22 (~990K of the ~28.9M CpGs) and use the full 68-sample cohort, since findSEMs’s outlier logic needs a reasonably large cohort to be meaningful; the same calls work genome-wide on your own data by simply passing the full bs object.

bs_demo <- bs[as.character(seqnames(bs)) %in% c("chr21", "chr22"), ]
sampleNames(bs_demo) <- pData(bs_demo)$"Sample ID" # guarantee unique sample IDs
bs_demo
#> An object of type 'BSseq' with
#>   991522 methylation loci
#>   68 samples
#> has not been smoothed

Imprinting control regions (ICRs)

findICRs scans for windows of consecutive, densely-spaced CpGs that are consistently hemimethylated (or monoallelic, in gamete tissue) across the cohort – the signature of genomic imprinting – following the approach of Jima et al. 2022.

icrs <- findICRs(bs_demo, minCov = 4, minSample = 0.5, ncores = 4)

Stochastic epigenetic mutations (SEMs)

findSEMs flags, per sample and per CpG, methylation values that are extreme outliers (Tukey-fence based) relative to the rest of the cohort at that CpG – these are stochastic epigenetic mutations. saveIndSEMs = TRUE additionally writes out the long-format per-event table (sampleSEMs.rda) that annotateSEMs needs.

sample_sems <- findSEMs(
  bs_demo, minCov = 10, minSamples = 50,
  saveIndSEMs = TRUE, saveDir = tempdir(), ncores = 4
)

Finally, goSEMs runs GO/KEGG over-representation on the genes that came out significant, against a proper background gene universe rather than the whole genome:

sig_genes <- gene_test$results$gene[gene_test$results$FDR < 0.25]
if (length(sig_genes) > 0) {
  go_res <- goSEMs(sig_genes, universe = sem_annotated$universeGenes, runKEGG = FALSE)
  head(as.data.frame(go_res$GO))
} else {
  message("No genes passed the demo FDR cutoff on this small chr21+chr22 subset -- ",
          "expected on a 2-chromosome slice; try the full genome on real data.")
}

Part 2: Prediction

These functions predict one value per sample and run comfortably on a handful of samples, so we go back to the fast 3-sample bs_small object and use the full genome (needed for predictSex’s coverage signal, and for reliable coordinate/CpG matching against each predictor’s bundled panel).

Genetic sex and sex-chromosome karyotype

predictSex needs no training data: it estimates each sample’s copy number on chrX/chrY relative to the autosomal baseline from raw coverage alone, and classifies against theoretical karyotype centroids (XX, XY, X0/Turner, XXY/Klinefelter, XXX/triple X, XYY).

sex_res <- predictSex(bs_small)
#> [predictSex]: computing autosomal baseline coverage (median) for 3 samples
#> [predictSex]: computing chrX (non-PAR) coverage
#> [predictSex]: computing chrY (non-PAR) coverage
#> [predictSex]: classifying samples against reference karyotypes
#> [predictSex]: predicted sex breakdown:
#> 
#> F

#> 104-SIK 104-SIK        XX            F

Array emulation
